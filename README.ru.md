# API продавца KEYPLO

Серверный API аккаунта, баланса, каталога, цен и покупок. Справочник EN/RU и OpenAPI.

[Interactive API reference](https://keyplo.com/docs/?lang=ru) · [OpenAPI](./openapi.json)

## Начало

1. Владелец создаёт аккаунт. Пополните кредит USD в кошельке через счёт USDT от FazerCards или получите кредит от владельца.
2. Лично создайте API-ключ в разделе «Интеграции» и храните только на сервере.
3. Вызовите GET /me и GET /balance.
4. GET /products?kind=gift_card возвращает категории; передайте category_id для товаров.
5. POST /quotes: product_id, quantity, fields.
6. POST /orders: те же данные плюс external_id, max_total_minor и постоянный Idempotency-Key.
7. Проверяйте GET /orders/{id}; выдавайте товар только при status=completed.

## Защита

Суммы USD в центах. Не меняйте ключ идемпотентности для повторной покупки при неопределённом результате. Сначала проверьте статус. unknown и needs_review требуют сверки владельцем. Публичного API пополнения нет. Проверка и сопоставление товаров GGsel, Digiseller и FunPay ещё разрабатываются; ссылка выдачи не включает автоматическую покупку. Номинальное пополнение Steam пока не предоставляется: опубликованный курс не включает комиссии конкретного аккаунта.

120 запросов/минуту на аккаунт, 240 на IP; JSON до 16 КБ; только HTTPS и Authorization: Bearer. Ключи в URL не принимаются.

[Python](./examples/client.py) · [Node.js](./examples/client.mjs) · [PHP](./examples/client.php)

Просмотр подарков Steam использует выборку первых 500 игр с постраничной навигацией. Передайте числовой Steam App ID в category_id для другой игры. Списки категорий могут кэшироваться на пять минут; расчёт покупки всегда обновляет цену.

## Пополнение клиента

Кошелёк создаёт личный счёт поставщика. Способы оплаты и лимиты загружаются из FazerCards. Используйте только указанные актив, сеть, точную сумму и memo. Кредит USD зачисляется один раз после подтверждения платежа и завершённого зачисления средств поставщиком. Оставьте кошелёк открытым для проверки или вернитесь и нажмите «Проверить платёж». Неопределённый счёт не создаётся повторно автоматически. Пополнение доступно в кабинете; публичного метода создания счетов API нет. Реальное оплаченное пополнение пока не проверено.
